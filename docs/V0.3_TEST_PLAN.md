1. Open the GitHub Pages build in Chrome on Android.
2. Start the game and enter a player name.
3. Verify joystick movement.
4. Verify swipe camera.
5. Verify jump and sprint.
6. Approach the terminal and press ACTION.
7. Complete Signal Run.
8. Enter Lumen Wilds through the Central Gate.
9. Speak with Scout.
10. Activate Relay 1, Relay 2 and Relay 3.
11. Collect at least one optional Lumen Shard.
12. Set the checkpoint.
13. Touch a hazard and confirm respawn at the checkpoint.
14. Awaken the Shrine.
15. Use the Return Gate.
16. Confirm the completion screen appears.
17. Use RADAR in both zones.
18. Toggle SOUND.
19. Cycle GRAPHICS HIGH -> MEDIUM -> LOW.
20. Change AVATAR style and reload the page.
21. Confirm local progression persists after reload.

## Regression checks
- [ ] No accidental movement outside zone bounds.
- [ ] Buildings and grove obstacles block the player without trapping the player.
- [ ] No interact prompt for hidden/inactive objects.
- [ ] No challenge can remain active after a zone transition.
- [ ] No duplicate rewards after repeated interaction.
- [ ] Repeated hazard contact does not create a respawn/alert loop.
- [ ] Save/load does not corrupt mission state.
- [ ] Mobile HUD remains usable in landscape and portrait.
- [ ] No sustained visual drift of world geometry.
- [ ] Acceptable frame rate on the target Android device.

## Sign-off rule
V0.3 can move the total project metric from 10% to 20% only after the unresolved manual/automated checks above are completed and recorded.
